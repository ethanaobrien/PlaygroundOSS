# Playground OSS

This is the 'Playground' game engine and is released in open source under Apache License v2.0.

 * All the needed documentation is in the /Doc folder.
 * Source code are under the /Engine folder.
 * Tool to compile a sample project is under /Tools folder.
 * Sample showing the scripting APIs are available under the /Tutorial folder.

Other folders (CSharpVersion, SampleProject) are more related to prototype features or detailed implementations.

To get started, please read the /Doc/Project.md

Modern multi-platform build work is documented in
[`Doc/Modernization.md`](Doc/Modernization.md). Exact prerequisites and commands
for every supported target are in
[`Doc/BuildAndRun.md`](Doc/BuildAndRun.md). The historical platform
projects remain available as compatibility references while the modern CMake
and SDL3-based host layers are introduced incrementally.
Nintendo Switch/libnx development, installed-title packaging, storage policy,
and hardware acceptance are documented in
[`Doc/SwitchPort.md`](Doc/SwitchPort.md).
