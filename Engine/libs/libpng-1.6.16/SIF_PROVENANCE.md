# libpng source provenance

This is the official libpng 1.6.16 tag at commit
`88dd30b232362b65cca374dda39096888163dd6b`.  The observed GitHub tag archive
`v1.6.16.tar.gz` has SHA-256
`6b4aeacdda7ba0047e15848d0ec6af0425961e07ebb1b913ed55005bf463945c`.
The target embeds the matching version and release-date strings.

`config/x86_64-android/pnglibconf.h` is byte-identical to the upstream
`scripts/pnglibconf.h.prebuilt`, SHA-256
`55ff0d1cc10238c745a1e570a76c2a7fad97fae1103cf3157ec2456861c7af51`.
The x86-64 target uses the fifteen portable library translation units and no
ARM optimization sources.
